# Codex 会话监控 1.1.1

Windows x64 便携版，包含从公开版 1.0 到 1.1.1 的全部更新。

## 本次更新

- 简化模式加入单会话之外的七种汇总范围：近 60 秒有输出、最近 24 小时、全部未归档、仅主会话、仅子会话、当前列表筛选、含归档全目录。前五种只含未归档会话；列表筛选跨页计算。
- 可选记录 60 秒输入、缓存与缓存命中率，持久保存已确认的累计输入／输出／缓存；默认关闭，在设置中开启。
- 自选小窗指标、窗口置顶、观察对象与范围保存；隐私模式同时作用于完整界面和简化模式。
- 优化小窗口布局，将高度优先留给会话列表，详情按需展开。
- 汇总复用采样快照，显示覆盖数和部分小计；缓存命中率按有效输入／缓存配对加权计算。

## 下载与升级

- `CodexSessionMonitor-1.1.1-windows-x64.zip`：解压即用，含 GUI、Agent CLI、源码、说明和许可；无需 Python。
- `CodexSessionMonitor-1.1.1.exe`：独立 GUI；需要 Agent CLI 时请使用 ZIP。
- `SHA256SUMS.txt`：上述下载文件的 SHA-256 校验值。

关闭旧监控器后，用新版替换程序，或解压到新文件夹运行。配置与可选统计仍在 `%LOCALAPPDATA%/CodexSessionMonitor/`，不需要复制私有日志；保留旧版偏好。ZIP 为免安装便携包，不修改 Codex 安装。

## Agent 与数据边界

产品版本 1.1.1，Agent JSON schema 仍为 1.0；四个命令保持 `capabilities/list/diagnose/plan`。GUI 持续 Token 记录、私有统计库与简化汇总未开放为 CLI 接口。调用方式见 [Agent 说明](https://github.com/JingWang-Star996/cancer-session-rescue/blob/monitor-v1.1.1/docs/monitor-agent-api.md)。

缓存属于输入；累计不能恢复早期未知重置，跨会话不去重共享历史。冷会话采样可能延迟，读数不代表逐字流速或账单。监控器只读会话日志，可选写入自己的统计库；没有生产日志 apply 命令，也不自动调用模型。旧 `csr --apply` 是独立工具。

## 验收

64 项回归中 63 通过、1 项目录符号链接测试因系统权限跳过；9 组原生控件尺寸／缩放验证，960×600 下显示 9–11 行；5,000 条合成会话汇总正确。冻结 Agent CLI 四命令、UTF-8、匿名输出与拒绝覆盖源文件检查通过。1.1.0 的持续记录核心已完成 75 秒实机记录和重启恢复，1.1.1 汇总补丁未改变该核心。这些是测试环境结果，不是所有电脑的性能保证。公开包不含真实会话和私有统计库。
