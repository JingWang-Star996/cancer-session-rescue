# 1.0.0 · 2026-10-12

本次升级针对大量历史会话带来的持续采样和表格重绘开销。

新增分层采样、全局读取预算、低频目录巡检、冷文件轮转、分页与差量绘制。设置支持间隔和每页条数热更新；最小化降频，暂停时丢弃过期结果。

增加未归档/已归档体积拆分、只读优化诊断、Agent 任务包、独立 JSON CLI 和 GitHub 设置。延续隐私开关与匿名导出。

修复已消失文件保留旧体积、物理文件别名重复计入、冷会话首次聚焦把未观察输出计入速率等问题。

边界：诊断有读取预算；本版没有生产日志改写命令。降频会延迟观察，冷会话首次聚焦先建立基线。
